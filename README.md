# HiForestProducerTool

In this repository, you will find a collection of simple examples that use CMSSW EDAnalyzers to extract trigger information and generate ROOT Hiforest files from the CMS public heavy-ion datasets.

There are four main branches in this repository, each corresponding to a specific heavy-ion data release from CMS:

- [2010](https://github.com/thiagorangel45/HIOpenDataAnalysis-Pt/tree/2010)
- [2011](https://github.com/thiagorangel45/HIOpenDataAnalysis-Pt/tree/2011)
- [2013](https://github.com/thiagorangel45/HIOpenDataAnalysis-Pt/tree/2013)
- [2015](https://github.com/thiagorangel45/HIOpenDataAnalysis-Pt/tree/2015)

Each branch contains the specific setup and instructions needed to work with that year's dataset. Please refer to the `README.md` file in each branch for detailed guidance.
